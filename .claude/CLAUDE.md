# Project instructions

## Git

- Always push finished work straight to `main` on this repo (`git push origin HEAD:main`, fast-forward only, never force). The owner has standing approval for this; do not stop to ask or leave work parked on a branch.
- Run `npm test` first; do not push with failing tests.
- Work in a worktree branch as usual, then push it to `main`. The branch can be pushed too if useful, but `main` is the destination.
